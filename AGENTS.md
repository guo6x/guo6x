# Agent instructions for the personal portfolio

The owner's long-term mission is to broaden participation in space exploration. The website should be worthy of an engineering founder's long-term reputation while accurately stating that he is currently an undergraduate and the physical projects remain early-stage.

Before visual changes, read `DESIGN.md` and review these public skills:
- https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md
- https://vercel.com/design/guidelines

Honor the existing static bilingual GitHub Pages architecture. Do not introduce React/Next.js, npm dependencies, remote fonts, large 3D engines, decorative autoplay media or analytics without a demonstrated need.

When editing:
1. Work in a branch, write the conceptual design goal, and then implement.
2. Keep `index.html` and `en/index.html` content and structure aligned.
3. Retain a visible high-quality first screen, strong contrast and responsive mobile layouts.
4. Keep all claims evidence-qualified. The rocket's software tests are not physical-flight approval.
5. Never invent external social accounts, personal details, live-user metrics, funding, clients or product certification.
6. Preserve approved WeChat QR/contact URL unless the owner explicitly provides a replacement.
7. Keep SVG concept art identified as illustrations; never present drawings as measured or approved mechanical parts.
8. Run `node --check assets/stellar-site.js` and `node scripts/check-portfolio.mjs`.
9. Use real screenshots/browser testing when available, and explicitly state if that verification was not possible.
10. Avoid generic gradient-glass card kits and excessive motion. Favor a single memorable aerospace focal point, excellent type and evidence-rich case studies.
