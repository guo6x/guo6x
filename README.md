## 我的长期目标

**让更多普通人也有机会探索太空。**

我知道这不是凭一个项目或几行代码就能做到的。航天需要制造、控制、材料、试验、资金、团队，以及对安全与证据的尊重。

因此我选择从眼前能完成的事情开始：**用 AI 和软件解决真实问题，逐步积累商业和工程能力，再把这些积累带向航天。** 具体路径会随着机会和证据调整，目标不需要提前锁死在某一种飞行器上。

> **Build. Test. Learn. Repeat.**  
> 做出来、验证它、纠正错误，然后继续。

## 我是谁

我叫 **郭家吉（Jiaji Guo）**，2024 年进入 **南昌航空大学科技学院**，学习 **飞行器制造工程（Aircraft Manufacturing Engineering）**。

大学期间，我持续开发 AI 软件、开源工具和航空航天相关的工程实验。2026 年暑期，我在杭州参与了 AI 工作流和协作软件的开发实践。

我喜欢跨界，但不认为“做过原型”就等于“完成产品”，更不会把软件测试结果包装成实物飞行验证。

### 我当前关注的问题

- **AI Agent 与工程软件：** 如何让模型使用证据、调用工具、验证执行结果，而不是仅仅输出看起来合理的内容？
- **航空航天与控制工程：** 如何把课堂上的动力学、控制、仿真和嵌入式知识转化为可验证的实验系统？
- **产品与创业：** 如何真正为用户节约时间、成本或减少失误，并从用户反馈中验证商业价值？
- **长期探索：** 如何为更广泛、更可及的太空探索积累技术、组织与资源？

## 我如何推进这个理想

1. **近期：** 研究真实痛点，开发 AI 工具与软件产品，寻找能被用户验证的价值。
2. **中期：** 深入机械工程、控制、测试与软硬件协同，积累可靠的工程判断与合作经验。
3. **长期：** 在合适的技术、资源和组织条件下参与建设航天企业，让太空探索离更多人更近。

这是一条探索路线，而不是承诺了时间表的融资或产品计划。
